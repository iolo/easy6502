# easy6502
[![라이선스: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

Nick Morgan이 만든 Easy6502는 6502 어셈블리 언어 프로그래밍을 한곳에서 쉽게 배울 수 있는 튜토리얼입니다.
내장 에뮬레이터에서 직접 수정하고 실행할 수 있는 다양한 예제 프로그램을 제공합니다.

실제 사이트는 http://skilldrick.github.io/easy6502/ 에서 확인할 수 있습니다.

이 원본 포크는 현재 유지보수만 진행하고 있습니다. 버그 수정을 위한 풀 리퀘스트는 환영합니다.

튜토리얼과 에뮬레이터의 추가 개선 및 개발 내용은 활발히 개발 중인 다른 포크를 참고하세요.
https://github.com/skilldrick/easy6502/network
